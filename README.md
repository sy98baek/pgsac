# Patchwise Graph Spectral Attention with Codebook

This is the code for training the PGSAC backbone, which is presented in [WACV 2026 paper](https://ieeexplore.ieee.org/document/11492687).

The dataset is available at : https://drive.google.com/drive/folders/1isSffnAmu0Dm6uGRpTBcx5PMLVFrKxQJ?usp=sharing
The GT illuminants for the custom dataset is available at illuminant_gt.py.
